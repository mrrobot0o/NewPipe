## ✨ Teresa Features

### 🎨 Beautiful UI/UX
- **Motion Graphics** - Smooth animations and transitions
- **Material Design 3** - Modern UI components
- **Dark/Light Theme** - Easy on the eyes
- **Customizable** - Personalize your experience

### 📺 Streaming
- **YouTube** - Watch without ads
- **Background Playback** - Listen while using other apps
- **Popup Mode** - Floating video player
- **Download** - Save videos for offline viewing

### 🚀 Performance
- **Lightweight** - Uses minimal resources
- **No Google Services** - Works without Google Play Services
- **Privacy Focused** - No tracking, no data collection

## 🎬 Motion Graphics

Teresa features beautiful motion graphics:
- **Splash Screen Animation** - Elegant loading animation
- **Transition Animations** - Smooth screen transitions
- **Lottie Animations** - High-quality vector animations
- **Micro-interactions** - Delightful UI feedback

## 📥 Installation

### Download APK
Download the latest release from [GitHub Releases](https://github.com/mrrobot0o/NewPipe/releases)

### Build from Source
```bash
git clone https://github.com/mrrobot0o/NewPipe.git
cd NewPipe
./gradlew assembleDebug
```
